## 读出的八条主线

十三年写下来，他的世界观其实很稳定，翻来覆去就这几件事：

1. **工具哲学：把权力还给人** — `File over app` / `Self-guaranteeing promises` / `Use the saw, fear the saw` / `Every app is a superpower` / `Photoshop for text`。软件会死，文件要活；工具越强，越要让人学会驾驭而不是被管。
2. **反 VC，挺独立软件** — `100% user-supported` / `Quality software deserves your hard-earned cash`。他造了个词 **VCware**：拿 VC 钱 → 补贴获客 → 画大饼 → 产品烂掉（enshittification）→ exit。Obsidian 不拿 VC 是原则，不是姿态。
3. **好设计 = 选对妥协** — `Design is compromise` / `Great tools choose to be bad at some things` / `Style is consistent constraint` / `Be vanilla` / `What can we remove?` / `Black pixels`。面面俱到等于哪样都不卓越；主动选择"不行什么"，才换得来"极强什么"。
4. **笔记即思考** — `Evergreen notes` / `How I use Obsidian` / `Concise explanations accelerate progress` / `Don't delegate understanding` / `A camera for ideas`。把想法变成可以摆弄的对象；理解不能外包。
5. **行动与习惯** — `A little bit every day` / `Nibble and your appetite will grow` / `How I do my to-dos` / `Caloric energy is precious` / `40 questions`（年/十年）/ `Stadium of selves`。行动先于灵感；最小进步单元；用电能换回对卡路里的自由。
6. **人性观：乐观、共情、爱** — `Default to empathy` / `Choose optimism` / `Love is freedom` / `Scars are beautiful` / `Pain is information` / `Calmness is a superpower` / `In good hands`。22 岁决定当乐观主义者；爱是自由；疤是勋章。
7. **宇宙尺度** — `Earth is becoming sentient` / `Agents of chaos` / `A bicycle for the senses` / `The elusiveness of digital paper`。地球是正在获得 sentience 的身体，我们是细胞；感官的自行车；为白天造技术。
8. **职业与策略** — `Don't specialize, hybridize` / `Many ways to win`（80 种护城河）/ `Solving problem-finding` / `Always learning, always teaching` / `If you're remote, ramble`。T 型常见，U 型是 plateau-breaker；找题比解题难。

## 一个观察

- 他的写作本身就是 `Concise explanations accelerate progress` 的实践：短、清楚、可反驳可 remix——`Style is consistent constraint` 里他自述"写 500 词内的短文"，确实基本都做到了。
- 时间线有意思：2012–2015 偏意识流和硬件梦（做过一款没上市的头显），2016–2020 偏仪式与人生方法，2022 年后密集输出工具哲学——正是 Obsidian 爆发成长期。博客是他思考的年轮。
- 很多篇互相引用成网（`pain`↔`scars`，`file-over-app` 被引用 5+ 次）——正是他 `Evergreen notes` 理论的活例子：想法变成对象，互相堆叠。
