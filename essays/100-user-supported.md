# 100% user-supported

- 作者：Steph Ango (kepano)
- 日期：2024-02
- 原文：https://stephango.com/（直链未验证，请见博客首页）
- 主题：obsidian / startups / vc

摘要：解释 Obsidian 为什么 100% 用户支持、不拿 VC 的钱：想保持小团队；有不想妥协的严格原则；用户愿意付费支持。Obsidian 不会永存，没有 app 会；但你在 Obsidian 里创建的文件是你的，有望传代。VCware 只有五年 horizon，不是为几十年而建。很多创始人拿 VC 是因为真需要前置资本，或把它当增长捷径——有时资本真必要，但更多是出于不耐烦和硅谷惯性。短期 VCware 靠补贴定价获客，代价是囤积用户数据、锁定用户。为了持续融资必须画越来越大的饼，最终无法兑现，优先级分裂，产品变烂（enshittification）。所有 VCware 最终都要 exit；十个死九个是 VC 组合数学的一部分。VC 制造了"要么做大要么死"的必然压力。呼应《Self-guaranteeing promises》对 VCware 的批判。
金句："VCware is built with a five year horizon, it is not built to live on for decades."
