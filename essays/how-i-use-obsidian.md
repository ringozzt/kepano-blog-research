# How I use Obsidian

- 作者：Steph Ango (kepano)
- 日期：2023-09
- 原文：https://stephango.com/（直链未验证，请见博客首页）
- 主题：obsidian / tools / 笔记方法

摘要：他的自下而上笔记法：用 Obsidian 思考、记笔记、写文章、发布本站。vault 就是一个文件夹（file over app）。个人规则：不拆多个 vault；不用文件夹做组织；不用非标准 Markdown；分类和标签永远复数；大量用内部链接；日期全用 YYYY-MM-DD；7 分制打分；每周只留一个 to-do list。风格一致能把几百个未来决策坍缩成一个。组织：极少文件夹，大部分笔记在根目录（根=我写的/与我直接相关的）；References（写外部世界：书/电影/地点/人）、Clippings（存别人写的）；Attachments/Daily/Templates 三个管理文件夹。Fractal journaling：白天用 unique note 快捷键记碎片（YYYY-MM-DD HHmm），每几天汇总 salient thoughts，每月 review，每年用 40 questions 模板 review——织出可缩放的人生分形网。每几个月 "random revisit"：随机漫游 vault，用局部图谱看关联，补链接、修格式。有人问能不能用 LLM 自动化，他说不：我享受这个过程，维护帮我理解自己的模式——呼应《Don't delegate understanding》。发布流：Obsidian 写 → Obsidian Git 插件推 GitHub → Jekyll 编译 → Netlify 托管（本站就是这么来的）。
金句："It embraces chaos and laziness to create emergent structure."
