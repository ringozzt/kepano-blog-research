# Great tools choose to be bad at some things

- 作者：Steph Ango (kepano)
- 日期：2022-11
- 原文：https://stephango.com/（直链未验证，请见博客首页）
- 主题：design / tools

摘要：工具把"你能做的"变成"你想做的"：铅笔把手部动作变成纸上的思想。革命性工具都是让贵的东西变便宜，但让一样东西变便宜通常意味着让另一样变贵。设计空间是"难度轴"构成的，翻转某根轴是允许的：让 A 更难一点，换 B 容易得多，值。呼应《Design is compromise》。3D 建模让旋转/换视角/换材质变便宜，代价是你要建模+渲染；synthography 让整场景渲染和跨风格发散变便宜，代价是输出压平成一层、对单个元素控制弱。别批评工具不擅长什么，别设计面面俱到的工具——主动选择在某件事上"不行"。
金句："Resist criticizing tools for what they are bad at. Resist designing tools that are well-rounded. Instead, choose to be bad at something."
