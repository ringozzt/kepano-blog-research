# Black pixels

- 作者：Steph Ango (kepano)
- 日期：2023-06
- 原文：https://stephango.com/black-pixels
- 主题：hardware / design

摘要：他第一份工业设计工作就是做一款未上市的头显（小创业公司，双 micro-OLED，类似 Vision Pro，透过 beam-splitter 半透镜的 see-through 光学）。回头看，当年相信 see-through 光学更优是错的——2011 年时它看真实世界无延迟无畸变显得更好，但现在他确信 pass-through 显示才是近期正解。原因很简单：你需要黑色像素。科幻片里的 HUD/全息界面背景永远是暗的，因为那种显示只能投影光（从透明到白）。Vision Pro 演示了三件没有黑像素做不到的事：黑字黑底、虚拟阴影、环境调暗。要在 MR 里有真正的黑色，必须从底层控制渲染。结论：pass-through 更自然、更沉浸、应用更多。这是设计师的"第一性原理"式复盘。
金句："The reason is simple. You need black pixels."
