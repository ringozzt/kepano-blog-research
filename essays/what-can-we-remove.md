# What can we remove?

- 作者：Steph Ango (kepano)
- 日期：2024-06
- 原文：https://stephango.com/（直链未验证，请见博客首页）
- 主题：design / minimalism / 系统

摘要：人的偏见永远是加法：更多规则、流程、代码、功能、东西。依赖 proliferate，慢慢勒死我们。系统想不停生长，但不修剪就会崩溃——先慢后快。海滩上的一片垃圾，人人有责捡起；一千片时就晚了，只能哀叹"海滩本来就这样"。好的系统设计了定期清除 cruft 的机制，有内置的制衡。为什么加法比减法容易？也许因为我们把身份认同寄托在可见之物上。但要区分：定义风格的装饰（呼应《Style is consistent constraint》）和背负的 vestigial burdens。记住那些做"减法"这种 invisible work 的人：他们的遗产不是沙堡，而是我们玩耍的那片干净海滩。
金句："Their legacy was not to build a sand castle, but to care for the beautiful beach on which we play."
