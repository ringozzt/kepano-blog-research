# Style is consistent constraint

- 作者：Steph Ango (kepano)
- 日期：2023-09
- 原文：https://stephango.com/style
- 主题：design / minimalism / 风格

摘要：王尔德说"一致是没想象力的人最后的避难所"——对想法他同意（允许被改变主意），对流程他反对。风格从一致中长出来，有风格反而打开想象力：头脑要灵活，流程要可重复。风格就是你遵守的一套约束。约束可以是颜色、形状、材质、字体、语言、穿衣、装饰、信念、口味、声音、气味、仪式——你的风格不必取悦任何人，按自己的规则玩。他的几条：穿无 logo 纯色衣服；日期全 YYYY-MM-DD；标签复数；纯文本写作；每年 40 问；每周备餐、每周剃两次头；写 500 词内的短文。收集你喜欢的约束，怪约束让事情更好玩，随时可改。有风格把几百个未来决策坍缩成一个，给你 focus 和 leverage；也让你知道自己何时在打破约束——有时必须打破。附录收集了他人的风格怪癖：Scott Yu-Jan 把所有工具漆成白色、乔布斯黑高领、贝多芬数 60 颗咖啡豆、Wes Anderson 的 Futura 字体等。
金句："Style is a set of constraints that you stick to."
