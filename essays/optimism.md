# Choose optimism

- 作者：Steph Ango (kepano)
- 日期：2023-12
- 原文：https://stephango.com/optimism
- 主题：humanism / optimism

摘要：22 岁时意识到自己的世界观被悲观和犬儒浸透——那是他成长的文化。某天决定成为乐观主义者，生活变得好玩多了。悲观容易但沉闷（不花成本），乐观难但刺激（需要不断 reaffirm）。乐观主义三假设：未来可以很美好；人的意图大多是好的；想法很脆弱需要呵护。新想法都是未实现的梦，梦很易碎，见到想法先问"what would make this idea great?"。悲观和乐观都是自我实现的预言。呼应《Default to empathy》。
金句："Only optimists can create a great future. Only optimists can imagine it."
