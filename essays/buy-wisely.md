# Buy wisely

- 作者：Steph Ango (kepano)
- 日期：2023-09
- 原文：https://stephango.com/buy-wisely
- 主题：money / minimalism / 消费观

摘要：买东西的核心 heuristic 是 cost per use（每次使用成本），另有 cost per smile / thrill / externality / lesson。Cost per use=价格÷预期使用次数，奖励耐用可修：Darn Tough 羊毛袜贵四倍但终身保修，摊下来更便宜；好东西的 cost per use 趋近于零。也适用于健身房、医疗、流媒体订阅。评估耐用度的十几个问题：未来还一样有用吗？材料耐用可维护吗？风格 timeless 吗？会包浆（wabi-sabi）吗？保值吗？能拆修吗？零件通用吗？标准接口/电池吗？能改装升级吗？厂家活得比你想用的久吗？一物多用吗？有保修吗？依赖不耐用的东西吗？——呼应 "buy it for life" 运动。估算次数按使用频率（小时/天/周/月/年）猜；新手先借/租/试；最省的是不买不需要的。机会成本：花在低频物上的每块钱都是不能存下买高频物的钱。最值得 splurge 的是你用得最多的东西（一天坐 8 小时的椅子）。替代 heuristics：cost per smile（冰淇淋、日落、散步；他的电动自行车 joy per use 最高）、cost per thrill（辣酱、过山车、蹦极）、cost per externality（有机、公平贸易、隐私——把外部性内化进成本）、cost per lesson（知识的成本是钱/时间/痛苦，呼应《Pain is information》；买几手股票学投资胜过去读研；早期尝鲜 cost per use 差但 learning per dollar 高）。
金句："The best things to splurge on are the things you use the most."
