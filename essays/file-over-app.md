# File over app

- 作者：Steph Ango (kepano)
- 日期：2023-07
- 原文：https://stephango.com/file-over-app
- 主题：tools / obsidian / 数字所有权

摘要："File over app" 是一种哲学：想创造持久的数字制品，必须用你能控制的文件、易读取的格式；也是对工具制作者的呼吁：承认所有软件都是短暂的，把数据所有权还给人。埃及神庙的象形文字几千年可读，重要的是思想不是凿子。今天的数字制品大多失控：存服务器、锁登录、专有格式。转述他自己的话：想让你的文字在 2060/2160 年的电脑上可读，它得先能在 1960 年的电脑上可读。他自己用 Obsidian 写，但"Obsidian 会永存"是妄念，真正设计为持久的是那些纯文本文件。future me 这一个观众就足够让写作值得。
金句："In the fullness of time, the files you create are more important than the tools you use to create them."
