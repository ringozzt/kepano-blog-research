# Calmness is a superpower

- 作者：Steph Ango (kepano)
- 日期：2022-10
- 原文：https://stephango.com/calmness
- 主题：habits / humanism

摘要：开篇即《银河系漫游指南》封面上的星际旅行建议："Don't panic." Panic 是他最讨厌的感觉，他更喜欢 calm。冷静是超能力：焦虑压力愤怒时，你可以选择冷静。人们喜欢待在让自己冷静的人身边——因为总有可担心的事，小问题爱升级成大问题；冷静的人看起来更有帮助、看得更清楚。冷静是地基，上面能建任何东西：帮你解题、帮你珍惜所有、帮你聚焦重要。冷静是一种乐观和自信，可以练。你可以成为那个冷静的人。呼应《Choose optimism》。
金句："Calmness is a foundation that you can build anything on top of."
