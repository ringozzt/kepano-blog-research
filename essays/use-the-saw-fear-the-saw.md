# Use the saw, fear the saw

- 作者：Steph Ango (kepano)
- 日期：2025-10
- 原文：https://stephango.com/（直链未验证，请见博客首页）
- 主题：tools / ai / 工具哲学

摘要：学台锯时老师强调"机器想切掉你的手指——敬畏锯子"。强大的工具能做强大的事：想做手工木家具就必须锯木头；想要四肢健全和想要家具并不矛盾，前提是学会安全地使用工具。有能感应手指自动停机的台锯，但没有不切手臂的电锯——工具的安全上限是"功能不受损"的边界。不应因危险而停止制造强大的工具，而应让人学会安全地使用强大的工具。"我用锯，我畏锯。我有手工家具，四肢健全。"——这是他一贯工具哲学的最新表达，也是对 AI 时代"强大工具危险论"的回应。
金句："We should not stop making powerful tools because they are dangerous. Rather, we should empower people to use powerful tools safely."
