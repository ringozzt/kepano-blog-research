# 40 questions to ask yourself every decade

- 作者：Steph Ango (kepano)
- 日期：2022-01
- 原文：https://stephango.com/40-questions-decade
- 主题：rituals / humanism

摘要：他每年问自己 40 个问题复盘过去十二个月（见《40 questions to ask yourself every year》），并和亲友讨论。进入 2020s，他想起曾答过普鲁斯特问卷——年度问题偏事件复盘，普鲁斯特问题偏少变的个人哲学，于是综合两者做了"十年版 40 问"，打算 2030 年再看。问题在 GitHub 开源，有 31 种语言翻译。40 问摘录：如果只剩 6 个月生命你做什么？有十亿美金你做什么？给十年前自己什么建议？希望十年后什么不变/改变？完美幸福的定义？何时何地最幸福？为什么起床？最低谷？最显著的性格？最大的恐惧？最讨厌自己/他人的特质？何时撒谎？最大的奢侈？最被高估的美德？想给全世界每人一份礼物送什么？最后悔？想怎么死？座右铭？什么让你有希望？
金句："Please edit this list with questions you would like to know your own answers to in ten years."
