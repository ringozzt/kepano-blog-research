# A bicycle for the senses

- 作者：Steph Ango (kepano)
- 日期：2023-06
- 原文：https://stephango.com/（直链未验证，请见博客首页）
- 主题：ai / hardware / computing

摘要：七十年来的计算机增强的是大脑（思考和记忆），下一代计算机将增强感官（视听触嗅味）。Spatial computing（AR/VR）之外，他提出更广的范式 sensory computing——手机是窥见这个世界的钥匙孔，现在门要开了。他学的是生物+工业设计 hybrid，乔布斯"计算机是头脑的自行车"（骑车的人能效碾压神鹰）的类比一直打动他，于是问：感官的自行车长什么样？耳朵的自行车：AirPods 是第一款大众版，降噪+通透模式替换并增强听觉；耳机变耳机电脑，可编程的听觉——实时翻译（银河系漫游指南的巴别鱼）、像蝙蝠一样"看"（Nagel 的 umwelt 概念：每种生物的感官总和即它的现实）。眼睛的自行车：头显把感官延伸直接接进视觉，叠加超人类传感器和在线数据；呼应《Every app is a superpower》——从自然界借超能力：蛇感热、鸟感磁场、鹰的视力、猫夜视、鲨鱼感电流、变色龙 360° 视觉；并可沿尺度/波长/时间/文化/空间/视角/解释七个向量扩展。鼻子？电子鼻+神经网络数字化气味，把嗅觉转成视觉图案（烹饪、医疗）；触觉的"第二层皮肤"softwear。文末注：这是他 2011-2013 年做一款未上市头显时的私人笔记，Vision Pro 让他翻出来修订。
金句："We are advancing towards a set of technologies that will expand and personalize our individual umwelt."
