# Photoshop for text

- 作者：Steph Ango (kepano)
- 日期：2022-10
- 原文：https://stephango.com/photoshop-for-text
- 主题：ai / tools / writing

摘要：修图有几十种滤镜，修文只有剪切复制粘贴——但这正在改变。预言"文字版 Photoshop"：像调滤镜一样改写、缩写、扩写、换文体（文学/技术/新闻/法律）、换人称、叙述改对话。类比 Photoshop 当年把暗房技术（dodge/burn）数字化。他造了个词 "synthscribed"（synthetic + described/transcribed，对应他在《A camera for ideas》里造的 synthography）。关键主张：语言模型必须跑在本地设备上，才能 private、offline、future-proof。
金句："transforming text will become as commonplace as filtering images."
