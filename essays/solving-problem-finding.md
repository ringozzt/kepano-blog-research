# Solving problem-finding

- 作者：Steph Ango (kepano)
- 日期：2018-09
- 原文：https://stephango.com/solving-problem-finding
- 主题：startups / ideas

摘要：解题有方法论（科学方法），但"找题"没有，这是教育体系的漏洞——很多人把宝贵岁月花在不重要的问题上。"写你所知"应推广为"做你所知"，但没有深耕一行很难找到好问题：要么问题太个人、帮不了几个人，要么收益太小。值得解的问题往往不明显——因为当事人要么放弃了，要么习以为常到看不见。建议：进一个行业干几年，从内部理解低效，亲手干、感受痛，保持好奇，直到看见全貌。你工作中要解的题往往不是真正重要的题，真正的问题更 meta：你为什么要花时间解这些小题。去解"你能力范围内最大的问题"。
金句："The problem you should solve is the biggest problem you are capable of solving."
