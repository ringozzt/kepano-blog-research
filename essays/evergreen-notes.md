# Evergreen notes turn ideas into objects that you can manipulate

- 作者：Steph Ango (kepano)
- 日期：2022-09
- 原文：https://stephango.com/evergreen-notes
- 主题：obsidian / learning / 笔记方法

摘要：Evergreen notes 让你把复杂想法拆成小的可组合想法来思考。标题要精炼好记、能用在句子里，如 "A company is a superorganism"、"All input is error"、"Calmness is a superpower"。不需要同意一个想法才能把它变成 evergreen note；note 可以很短。他的例子："Creativity is combinatory uniqueness" 建在 "Everything is a remix" 之上。把想法变成对象，你就能摆弄它、组合它、堆叠它，不必同时装在脑子里。术语来自 Andy Matuschak。这是他整个 Obsidian 方法论的理论核心。
金句："Evergreen notes turn ideas into objects. By turning ideas into objects you can manipulate them, combine them, stack them."
